# JG Mart Demo Script
**Duration**: 2-3 minutes  
**Tone**: Practical, problem-solving, community-focused  
**Target**: Recruiters, product managers, startup founders

"Hi, I'm Fahad Ibrahim. This is JG Mart — a hyperlocal grocery delivery PWA for Japan Garden City, Dhaka. It's built for a 1,700-family residential complex as the pilot target — 27 buildings — with WhatsApp-native ordering and zero cloud lock-in."

## Show: User Flow (0:15-0:45)
- Open app on mobile
- Browse products by category

## Show: Operator Features (0:45-1:15)
- Operator dispatch view
- Order status updates
- Cluster-based routing

## Show: Technical Architecture (1:15-1:40)

- IndexedDB persistence
- WhatsApp API integration
- Show: "Works without internet after first load"

## Closing (1:40-2:00)
"JG Mart demonstrates offline-first PWA architecture, real-world logistics, and community impact. The full case study is on my portfolio. Thanks for watching."
